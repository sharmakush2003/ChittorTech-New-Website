## 🛠️ Player Architecture & Features

All video overview components share a unified, high-converting UX design:
1. **Vertical 9:16 Mockup Frame**: Native smartphone chassis mockup with top notch & speaker bar.
2. **Zero Black Bars (`object-fit: cover`)**: Edge-to-edge aspect ratio matching vertical mobile video reels.
3. **Play/Pause Gradient Overlay**: High-visibility glowing play button preventing initial black frames.
4. **Playback Speed Switcher**: Interactive `1x`, `1.25x`, `1.5x`, and `2x` speed adjustments.
5. **Direct CDN Streaming**: Video chunks streamed directly from GitHub CDN without hitting hosting server bandwidth or Cloudflare cache quotas.
